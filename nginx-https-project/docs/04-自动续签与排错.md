# 04 - 自动续签与踩坑排错（实操记录）

## 一、自动续签

### 场景1：正式域名证书（备案生效后用）
Let's Encrypt 证书有效期 90 天，Certbot 装好时会自带 systemd timer 自动续签。
```bash
systemctl list-timers | grep certbot     # 查看自动续签定时器
certbot certificates                     # 列出所有证书及到期日
certbot renew --dry-run                  # 测试续签流程（不真换证书）
```
若需手动加 cron：
```bash
crontab -e
# 每天凌晨3点尝试续签，成功则重载Nginx
0 3 * * * /usr/bin/certbot renew --quiet --post-hook "systemctl reload nginx"
```
> `--post-hook` = 只有在证书真的更新后才执行后面的命令。

### 场景2：自签名证书（当前）
自签名证书固定 365 天，无法用 Certbot 续。到期前用
`docs/03-HTTPS配置.md` 第2步重新 `openssl` 生成并 reload 即可。
（这也是为什么项目最终要转成正式域名证书。）

## 二、踩坑全记录（面试可讲）

### 坑1：误选"宝塔Linux面板"应用镜像
- 现象：装完是图形面板
- 教训：学运维要选 **Ubuntu 22.04 系统镜像**，手动敲命令才练技术，宝塔会绕过底层。

### 坑2：SSH `Permission denied (publickey)`
- 现象：本地 PowerShell `ssh root@IP` 直接被拒
- 原因：轻量服务器默认只允许密钥登录 / 22端口对本地公网受限
- 解法：改用阿里云 **Workbench** 或 **VNC管理终端** 进入（走阿里云内网通道）。

### 坑3：`Waiting for cache lock`
- 见 02 文档，开机自动更新占用 apt 锁，等待或手动清锁。

### 坑4：域名访问 502 / ping 不通
- 原因：**国内服务器域名未 ICP 备案**，被解析/访问层拦截；IP 访问不受影响。
- 解法：备案期间先用 IP + 自签名证书完成学习，备案生效后换 Certbot 正式证书。

### 坑5：HTTPS 访问 403 Forbidden
- 原因：`/var/www/html/` 无首页文件，Nginx 找不到 index 且未开目录列表。
- 解法：创建 `index.html`（见 03 文档末）。

### 坑6：Workbench 登录 SocketTimeoutException
- 现象：点远程连接报 `SocketTimeoutException ... ecs-workbench-inner-share`
- 原因：Workbench 网页后端瞬时抽风，与服务器、与Nginx**无关**（用
  `Test-NetConnection IP -Port 443` 能证明服务器仍活着）。
- 解法：重试登录 / 换浏览器 / 改用 VNC 管理终端。

## 三、常用排错命令速查
```bash
systemctl status nginx          # 服务状态
nginx -t                        # 配置语法测试
journalctl -u nginx -n 50 --no-pager   # 看Nginx最近50条日志
ss -tlnp | grep -E '80|443'     # 端口是否在监听
curl -k -I https://localhost    # 本机自测HTTPS（-I只看响应头）
ufw status                      # 防火墙规则
```
