# 第一步：准备环境

## 🎯 本步目标
准备一台云服务器，作为我们部署HTTPS的实验环境。

## 📋 您需要准备
- 一台云服务器（2核2GB内存，Ubuntu 22.04系统）
- 服务器的公网IP地址
- 服务器的root密码

## 🔧 操作步骤

### 1. 购买云服务器

**推荐平台：**
- 阿里云学生机：https://developer.aliyun.com/plan/student （¥9.9/月）
- 腾讯云学生机：https://cloud.tencent.com/act/students （¥10/月）

**购买时选择：**
- 系统：Ubuntu 22.04 LTS 64位
- 配置：2核2GB内存
- 地域：选离你近的

### 2. 连接服务器

打开终端（PowerShell或Terminal），输入：

```bash
ssh root@你的服务器IP
```

然后输入密码（密码不会显示，直接输完按回车）。

### 3. 更新系统

连接成功后，执行以下命令：

```bash
# 更新软件包列表
sudo apt update

# 升级已安装的软件包
sudo apt upgrade -y
```

### 4. 安装必要工具

```bash
# 安装常用工具
sudo apt install -y curl wget git vim net-tools
```

## ✅ 验证清单
- [ ] 能成功用SSH连接服务器
- [ ] `sudo apt update` 能正常执行
- [ ] `curl --version` 有输出

## 💡 常见问题

**Q：SSH连接被拒绝？**
A：检查服务器是否已开机，安全组是否开放了22端口。

**Q：密码输错怎么办？**
A：重新输入密码即可，输错会提示"Permission denied"。

**Q：apt update很慢？**
A：可以换国内源，阿里云服务器默认就是国内源，应该很快。
