# Nginx + Let's Encrypt 自动化HTTPS部署项目

## 📋 项目简介

这是一个**企业级运维实战项目**，学习如何为网站部署HTTPS安全证书，并实现自动化管理。

### 🎯 项目目标
- 为网站启用HTTPS加密访问
- 实现SSL证书自动申请、自动部署、自动续期
- 配置安全加固，达到A+级安全评分

### 📊 预期成果
| 指标 | 改造前 | 改造后 |
|------|--------|--------|
| 部署HTTPS时间 | 2小时 | 5分钟 |
| 证书管理方式 | 手动 | 全自动 |
| SSL Labs评分 | C级 | A+级 |

## 🛠️ 技术栈
- **Nginx** - Web服务器
- **Let's Encrypt** - 免费SSL证书
- **Certbot** - 证书管理工具
- **Ubuntu 22.04** - 服务器系统
