# 第 1 课：环境搭建与核心概念

> 本课目标：① 脑子里有 Ansible 的工作模型 ② 电脑上有一个能跑的 Ansible 环境 ③ 亲手跑通第一条命令

## 一、先记住三个词（全部概念的地基）

| 概念 | 是什么 | 生活类比 |
|------|--------|----------|
| **控制节点** | 装了 ansible 的机器（你的电脑） | 导演 |
| **被管节点** | 被操作的远程机器（只开 SSH，零安装） | 演员 |
| **Playbook** | YAML 写的任务清单（要什么状态） | 剧本 |

执行一次任务时发生的事：

```
导演（控制节点）按剧本 → 把任务翻译成小脚本 → 通过 SSH 发给每个演员
→ 演员各自执行 → 回报结果：ok（本来就是这样）或 changed（我改好了）
```

> [!tip] 旁批：为什么「无 agent」是杀手锏
> 竞品（Puppet/SaltStack）要求先在每台被管机器上装客户端——可"装客户端"这件事本身就得逐台登录做一遍，鸡生蛋问题。Ansible 走 SSH，而**每台 Linux 天生就有 SSH**，所以零准备直接开工。

## 二、环境搭建（Windows 用户路线）

Ansible 官方不支持 Windows 做控制端，我们用 **WSL2**（Windows 里的完整 Linux，微软官方方案）。

### 步骤 1：安装 WSL2 + Ubuntu（一次性，需重启）

**右键开始菜单 → 终端管理员（或 Windows PowerShell 管理员）**，执行：

```powershell
wsl --install
```

> [!tip] 旁批：这一条命令做了四件事
> ① 启用「适用于 Linux 的 Windows 子系统」功能 ② 启用「虚拟机平台」功能 ③ 下载 WSL2 内核 ④ 安装默认 Ubuntu 发行版。执行完**重启电脑**才会生效。

### 步骤 2：首次启动 Ubuntu

重启后，开始菜单找到 **Ubuntu** 打开，第一次启动会要求：

```
Enter new UNIX username:  （小写英文，如 lin）
New password:             （输入时不显示，正常的，放心敲）
```

> [!warning] 旁批：密码输入不显示
> Linux 终端输密码**没有任何回显**（没有星号），这是安全设计不是卡死。输完直接回车。这个密码以后 `sudo` 时要用，记牢。

### 步骤 3：在 Ubuntu 里装 Ansible

```bash
# 更新软件源（让 apt 知道最新的软件清单，类似手机应用商店刷新）
sudo apt update

# 安装 Ansible
sudo apt install -y ansible

# 验证：看到版本号即成功
ansible --version
```

> [!tip] 旁批：apt 是什么
> Ubuntu 的包管理器，相当于 Linux 的应用商店命令行版。`apt install` 会自动处理依赖。`sudo` = 以管理员身份执行（安装软件需要管理员权限）。

### 步骤 4：跑通第一条 Ansible 命令

```bash
# 让 Ansible 管理「本机」练手（localhost 也需要 ssh 或用 local 模式）
ansible localhost -m ping -c local
```

期望输出：

```
localhost | SUCCESS => {
    "changed": false,
    "ping": "pong"
}
```

> [!important] 逐段拆解这条命令（这就是"每段代码都讲清楚"）
> - `ansible` —— 调起 ansible 主程序（ad-hoc 模式：临时执行一条命令，不写剧本）
> - `localhost` —— 目标机器：本机（从 inventory 名单里选，localhost 是内置默认名）
> - `-m ping` —— `-m` = module（模块），`ping` 模块：测试目标机器是否可被 Ansible 管理（不是网络 ping！它测的是"SSH 通不通 + Python 在不在"）
> - `-c local` —— connection 插件选 local：本机练习时不走 SSH，直接本地执行
> - 输出 `SUCCESS` + `pong` —— 控制端和被管端握手成功，Ansible 工作的最小闭环跑通了

## 三、验证清单（打勾即过关）

- [ ] `wsl` 命令可用，开始菜单有 Ubuntu
- [ ] Ubuntu 内 `ansible --version` 有输出
- [ ] `ansible localhost -m ping -c local` 返回 SUCCESS

## 四、本课术语表

| 术语 | 含义 |
|------|------|
| ad-hoc | 临时命令模式：`ansible 目标 -m 模块`，不写剧本，用于一次性操作 |
| inventory | 主机名单：登记哪些机器归 Ansible 管、怎么分组 |
| module | 模块：Ansible 的功能单元（ping/apt/copy/service…），每个模块保证幂等 |
| playbook | 剧本：YAML 文件，把多个模块编排成完整任务 |
| WSL2 | Windows Subsystem for Linux：Windows 内运行完整 Linux 的官方方案 |
