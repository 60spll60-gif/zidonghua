# 简历项目实战 MOC

这是 **简历项目实战** 专栏的入口。每个项目都按统一模板编写：**简历写法 → 技术栈 → 分步操作 → 旁批注解 → 面试问答**，学完即可上手实操。

> [!important] 使用说明
> 1. **先抄简历写法**：每个项目开头都有现成的简历 bullet point，按你的实际数据改数字
> 2. **跟着步骤实操**：所有命令都经过验证，个人电脑 + 一台云服务器（学生机约 ¥10/月）即可全部跑通
> 3. **重点看旁批**：`> [!tip] 旁批` 里写的是容易踩的坑、面试考点、工具选型原因
> 4. **没有公司环境怎么办**：全部项目都可作为个人项目实操，简历上写"个人项目"同样有效——面试官更看重你能讲清每个决策的**为什么**

## 组合策略（简历怎么排）

> [!tip] 旁批：项目搭配比数量重要
> - **投运维/DevOps 岗**：CI/CD + K8s + 监控 = 黄金三角，覆盖"发布-运行-观测"全链路
> - **投 AI 应用岗**：RAG + Agent + 微调 = 完整能力栈，从用到改全覆盖
> - **投 AI 运维/AIOps 岗**：私有化 LLM 部署 + 监控 = 差异化竞争力，这类人市场极少
> - **投安全运维岗**：HTTPS自动化 + ELK日志平台 = 安全合规+可观测性，覆盖"防护-检测-响应"全链路
> - 简历项目**不超过 3 个**，每个能讲 15 分钟细节 > 列 5 个只能说名字
