# 家庭服务器搭建

## 目标

用一台旧电脑或树莓派，搭一个家庭服务器，跑 NAS + Docker + 内网穿透，实现文件共享、媒体中心、个人网站、自动下载。

## 关键任务

- [ ] 选硬件：旧笔记本/树莓派/N100 小主机均可，功耗低优先
- [ ] 装系统：Ubuntu Server 22.04 LTS，无 GUI 省资源
- [ ] 基础配置：固定 IP、SSH 免密登录、关密码登录防暴力破解
- [ ] 装 Docker + Portainer（Web 管理界面，告别命令行管容器）
- [ ] 搭 NAS：Samba 文件共享 + Nextcloud 私有云盘
- [ ] 搭媒体中心：Jellyfin（视频）+ Calibre-Web（电子书）
- [ ] 内网穿透：frp/Cloudflare Tunnel，出门也能访问家里的服务
- [ ] 自动下载：qBittorrent + Sonarr/Radarr，追剧全自动

## 踩坑预警

- 运营商大概率给了你内网 IP，frp/Cloudflare Tunnel 是必需品
- 树莓派 SD 卡不耐写——日志和数据库放外接硬盘
- 不要暴露 22 端口到公网，用 VPN 或 SSH 跳板机访问
