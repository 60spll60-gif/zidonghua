# Linux 基础

## 是什么

Linux 是一个开源操作系统内核，加上 GNU 工具链构成了完整的操作系统。绝大多数服务器、云平台、嵌入式设备跑的都是 Linux。你用的 Android 手机、访问的网站、AI 训练集群，底层都是它。

## 为什么重要

不会 Linux，运维就无从谈起。Docker 容器里是 Linux，Kubernetes 节点上是 Linux，CI/CD Runner 也是 Linux。哪怕你是纯 Python 开发，生产环境大概率也是 Linux。

## 核心要点

- **文件系统**：一切皆文件——硬盘、进程、网络连接都以文件形式暴露在 `/dev`、`/proc`、`/sys` 下。
- **用户与权限**：`root` 是超级管理员；`chmod 755` 的数字代表 拥有者/组/其他人 的 读(4)写(2)执行(1)权限。
- **管道与重定向**：`|` 把前一个命令的输出变成后一个的输入；`>` 写入文件，`>>` 追加。
- **进程管理**：`ps aux` 看所有进程，`top` / `htop` 实时监控，`kill -9` 强制终止。
- **软件包管理**：Ubuntu 用 `apt`，CentOS 用 `yum/dnf`，Arch 用 `pacman`——但 Docker 让包管理变得不那么重要了。

## 一句话带走

> Linux 不难——你只需要习惯「没有 GUI，只有命令行」。常用的 20 个命令能覆盖 80% 的日常工作。
