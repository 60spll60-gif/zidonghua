# 网络基础

## 是什么

计算机网络就是让多台机器互相通信的一套规则。核心四层：应用层（HTTP/DNS）、传输层（TCP/UDP）、网络层（IP）、链路层（以太网/WiFi）。运维最常打交道的是 TCP/IP 协议栈。

## 为什么重要

服务调不通、端口被占、DNS 解析失败——运维的日常故障有一半是网络问题。理解网络，才知道 `ping` 通但 `curl` 不通是怎么回事。

## 核心要点

- **TCP 三次握手**：SYN → SYN-ACK → ACK。建立连接后才传数据，可靠但慢。UDP 不握手直接发，快但可能丢包。
- **端口**：0-65535，一个 IP + 一个端口 = 一个服务。常见端口：22(SSH)、80(HTTP)、443(HTTPS)、3306(MySQL)、6379(Redis)。
- **DNS**：域名 → IP 的翻译官。`nslookup` 查解析，`/etc/hosts` 可本地覆盖。DNS 挂了，所有服务都不可用。
- **防火墙**：用 iptables/nftables 控制进出流量。云上还有安全组——不在安全组白名单里的 IP 连端口都摸不到。
- **HTTP/HTTPS**：状态码记几个关键的：200(OK)、301(永久重定向)、403(禁止)、404(没找到)、500(服务器挂了)、502(网关错误)。

## 一句话带走

> 网络就是「谁跟谁说话，走哪条路，说什么语言」。TCP 保证送到，UDP 保证够快。
