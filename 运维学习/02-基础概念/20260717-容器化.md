# 容器化

## 是什么

容器是一种轻量级的虚拟化技术，把应用及其所有依赖打包成一个「集装箱」，可以在任何 Linux 机器上一致运行。Docker 是最流行的容器引擎，Kubernetes（K8s）是容器的编排管理系统。

## 为什么重要

「在我机器上能跑啊」——这句话终结于容器。容器解决了环境不一致、依赖冲突、部署繁琐三大痛点。现在的微服务、CI/CD、云原生，全部建立在容器之上。

## 核心要点

- **镜像 vs 容器**：镜像是只读模板（类似 ISO），容器是镜像的运行实例（类似虚拟机）。一个镜像可以启动无数个容器。
- **Dockerfile**：用 `FROM` 选基础镜像，`RUN` 执行命令，`COPY` 放入文件，`CMD` 定义启动命令。层是增量的，改一行只重建后续层。
- **docker-compose**：用 YAML 编排多容器应用——Web + 数据库 + 缓存，一个 `up` 全起来。
- **Kubernetes 核心概念**：Pod（最小调度单元，一或多个容器）、Service（网络入口）、Deployment（声明式部署，滚动更新）。
- **容器不是虚拟机**：容器共享宿主机内核，启动快（秒级）、占用小（MB 级），但不提供完整隔离——安全敏感场景需要额外防护。

## 一句话带走

> Docker 让「在哪儿跑都一样」，Kubernetes 让「跑多少台都一样」。
