# AI Agent（智能体）

## 是什么

AI Agent 是一个能自主规划、使用工具、执行多步任务的 AI 系统。它不只是一问一答的聊天机器人，而是能「接任务 → 拆步骤 → 调工具 → 检查结果 → 调整重来」的自主执行者。

## 为什么重要

如果 LLM 是大脑，Agent 就是整个身体。2025-2026 年是 Agent 元年——从 AutoGPT 到 Claude Code、Manus、Cursor Agent，Agent 正在从玩具变成生产力工具。

## 核心要点

- **核心循环**：思考（Plan）→ 行动（Act）→ 观察（Observe）→ 反思（Reflect）→ 重复。
- **工具调用（Tool Use / Function Calling）**：Agent 能调用 API、读写文件、执行代码——这是它和纯聊天机器人的本质区别。
- **记忆系统**：短期记忆（上下文窗口）+ 长期记忆（外部存储/向量库），让 Agent 能跨会话保持状态。
- **多 Agent 协作**：多个专业 Agent 分工合作——一个规划、一个写代码、一个测试，类似软件开发团队。
- **当前局限**：长任务容易迷路（上下文漂移）、成本高（每步都调一次模型）、安全边界模糊。

## 一句话带走

> LLM 只会回答问题，Agent 会完成任务。差一个「行动能力」。
