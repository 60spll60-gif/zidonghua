# 提示工程（Prompt Engineering）

## 是什么

提示工程是通过精心设计输入文本，引导 LLM 产出目标输出的一系列方法。它不是编程，更像是一种「对话设计」——你怎么问，决定了它怎么答。

## 为什么重要

同样的模型，好的提示和烂的提示产出天差地别。掌握提示工程，等于掌握了从 LLM 榨取最大价值的钥匙。不需要改模型，只需要改问法。

## 核心要点

- **角色设定**：开头就告诉它「你是一位资深 Python 工程师」，输出质量立刻提升。
- **少样本提示**：给 1-3 个输入→输出示例，模型就能模仿格式和风格。
- **思维链**：加上「让我们一步步思考」，复杂推理任务准确率能翻倍。
- **结构化输出**：要求「用 JSON 格式输出」，减少后处理成本和格式错误。
- **避免陷阱**：不说「不要怎样」而要「请怎样」——否定句容易触发你不想提的内容。

## 一句话带走

> 提示工程不神秘——本质上就是把「心里想的」翻译成「模型能精准执行的」。越具体，越准确。
