# Linux 练习题：基础篇

> 建议：先在 Ubuntu/Debian 虚拟机、WSL 或容器中完成。涉及 `sudo`、删除和改权限的题目只在练习环境执行。

## 练习清单

1. 显示当前目录、当前用户和当前内核版本。
2. 在 `/tmp` 创建 `linux-lab/logs`，再创建一个空文件 `app.log`。
3. 找出当前目录下最近修改的 5 个文件。
4. 将 `app.log` 的权限设置为所有者可读写、其他人无权限。
5. 用一条命令统计 `app.log` 的行数、单词数和字节数。
6. 查找占用当前目录空间最大的 3 个项目。
7. 找出名为 `sshd` 的进程，并输出 PID 和完整命令。
8. 查看本机正在监听的 TCP 端口及对应进程。
9. 验证 `example.com` 是否能解析，并查看 HTTP 响应头。
10. 使用管道筛选当前进程列表中包含 `python` 的行。
11. 解释 `chmod 640 config.ini` 中的 `640` 分别代表什么。
12. 某服务启动失败时，写出你会执行的 3 个排错命令，并说明顺序。

## 参考答案

<details>
<summary>展开参考命令</summary>

```bash
# 1
pwd && whoami && uname -r

# 2
mkdir -p /tmp/linux-lab/logs && touch /tmp/linux-lab/logs/app.log

# 3（GNU/Linux）
find . -type f -printf '%T@ %p\n' | sort -nr | head -n 5

# 4
chmod 600 /tmp/linux-lab/logs/app.log

# 5
wc -l -w -c /tmp/linux-lab/logs/app.log

# 6
du -xhd1 . 2>/dev/null | sort -hr | head -n 3

# 7
pgrep -af sshd

# 8
ss -lntp

# 9
getent hosts example.com && curl -I https://example.com

# 10
ps aux | grep '[p]ython'
```

`chmod 640` 的含义是：所有者 `6 = 4+2`，即读写；所属组 `4`，即只读；其他用户 `0`，即无权限。

服务启动失败可以按「状态 → 日志 → 端口/配置」排查，例如：

```bash
systemctl status <服务名>
journalctl -u <服务名> -n 50 --no-pager
ss -lntp
```

</details>

## 自评标准

- **入门**：能独立完成 1～6 题，并说清 `640` 与 `600` 的区别。
- **合格**：能完成 1～10 题，遇到命令失败会保留错误输出。
- **进阶**：能把第 12 题写成自己的排错清单，并在下一轮迭代中补充真实案例。
