# Linux 文件系统与权限

## 一、路径与文件系统

Linux 使用一棵从 `/` 开始的目录树。路径分为绝对路径和相对路径：绝对路径从 `/` 开始，相对路径以当前目录为参照。

| 目录 | 用途 |
|---|---|
| `/etc` | 系统和服务配置 |
| `/var/log` | 经常变化的数据与日志 |
| `/home` | 普通用户的家目录 |
| `/tmp` | 临时文件 |
| `/usr/bin` | 大多数用户态命令 |
| `/proc` | 内核提供的进程和运行时信息 |
| `/dev` | 设备文件 |

常用探索命令：

```bash
pwd                         # 查看当前目录
ls -lah                     # 查看详细目录内容，包括隐藏文件
find /var/log -type f -name '*.log' 2>/dev/null
du -sh ./*                  # 查看当前目录下各项占用空间
df -h                       # 查看文件系统整体空间
```

## 二、用户、组与权限

每个文件都至少有三组权限：所有者（user）、所属组（group）、其他用户（other）。权限数字为读 `4`、写 `2`、执行 `1` 的相加值。

```text
-rwxr-x---
 │  │  │
 │  │  └─ other：--- = 0
 │  └──── group：r-x = 5
 └─────── user ：rwx = 7
```

因此 `chmod 750 deploy.sh` 表示所有者可读写执行，组用户可读执行，其他用户无权限。目录的执行权限表示「能否进入并访问其中的条目」，不只是运行文件。

```bash
id                         # 查看当前用户、组和 UID/GID
ls -l deploy.sh            # 查看所有者、组和权限
chmod u+x deploy.sh        # 给所有者增加执行权限
chmod 640 app.conf         # 配置文件常见的安全权限
chown app:app app.log      # 修改所有者和所属组，需要相应权限
```

## 三、排错原则

1. 先确认自己在哪：`pwd`、`whoami`、`id`。
2. 再确认目标是什么：`ls -ld path`、`file path`、`stat path`。
3. 最后按最小权限修改，不要为了省事直接使用 `chmod -R 777`。

> [!warning] 安全提醒
> `sudo` 会扩大命令权限。执行删除、递归修改权限或修改系统配置前，先用 `pwd`、`ls` 和 `--dry-run`（如果命令支持）确认目标。

## 一句话带走

> Linux 权限问题的核心不是「多试几个 chmod」，而是分清路径、用户、组、权限和进程实际身份。
