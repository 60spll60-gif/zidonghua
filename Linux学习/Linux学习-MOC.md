# Linux 学习 MOC

这是 **Linux 学习** 的独立入口，采用「知识 → 练习 → 复盘 → 迭代」的方式推进。每周自动化汇出和周回顾会继续扫描这里的笔记。

## 学习路线

1. [[02-基础概念/20260905-Linux文件系统与权限|文件系统与权限]]：路径、FHS、用户、组和 `chmod`。
2. [[02-基础概念/20260905-Linux进程与服务|进程与服务]]：进程、信号、systemd、日志与资源观察。
3. [[02-基础概念/20260905-Linux网络与排错|网络与排错]]：IP、端口、DNS、连接状态和排错路径。
4. [[03-练习题/20260905-Linux练习题-基础篇|基础练习题]]：先独立完成，再展开参考答案。
5. [[04-迭代任务/Linux学习迭代任务|迭代任务]]：按周设定目标、实操、复盘和升级笔记。

## 每日最小闭环

- [ ] 阅读或复习一个知识点（10 分钟）
- [ ] 在 Linux 环境完成一个命令练习（15 分钟）
- [ ] 把遇到的错误、输出和结论记录到迭代任务（5 分钟）
