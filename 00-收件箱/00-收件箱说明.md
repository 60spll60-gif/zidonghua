# 收件箱

这里是所有未经整理的 raw input。不要在这里组织，只负责快速捕获。

## 什么时候用收件箱？

- 阅读时看到的有趣链接
- 会议 / 课程中的临时记录
- 灵感、问题、待确认的想法
- 任何来不及细化的内容

## 收件箱处理规则

1. 每天睡前或工作结束前花 5 分钟看一眼。
2. 有价值的笔记：移动到对应 pillar 的 `02-基础概念` / `03-工具与实践` / `04-项目与案例`，并改写为永久笔记。
3. 过时的、无价值的：直接删除或移到 `99-归档`。
4. 保持收件箱条目数 < 20，避免堆积。
