# 每周回顾

## 流程

1. 运行 `python _系统/03-脚本/周回顾.py` 生成本周回顾报告。
2. 清空或迁移 `00-收件箱` 中的笔记。
3. 检查各 MOC 是否需要更新（[[AI学习-MOC]]、[[语言学习-MOC]]、[[运维学习-MOC]]、[[Linux学习-MOC]]）。
4. 在 Obsidian 中打开 Graph View，查看是否有孤立的笔记。
5. 选择 1-3 个永久笔记从 `seedling` 升级为 `evergreen`。

## 检查清单

- [ ] 收件箱已清空
- [ ] 新笔记已链接到 MOC
- [ ] 孤儿笔记已建立链接
- [ ] 至少一个笔记从 `seedling` 升级为 `evergreen`
- [ ] Linux 本周迭代任务已完成或记录阻塞原因
- [ ] Linux 练习题至少完成一组，并把错题沉淀为笔记
- [ ] 过时笔记已移入 `99-归档`
