# 查询知识库

你的整个 vault 就是你的第二大脑。有两种方式从中获取答案。

## 方式一：直接问我（推荐）

你在对话里直接提问，我会自动：

1. 用 `obsidian-cli search-content` 在你的 vault 中搜索相关笔记。
2. 读取匹配度最高的几篇。
3. 综合后给你一个带引用的答案。

**用法示例**：

> 「知识库里关于 Python 装饰器有哪些笔记？」

> 「AI学习中大语言模型相关的概念有哪些？」

> 「帮我回顾一下本周学了什么运维知识」

> 「把 AI学习 和 Python 里关于测试的内容结合起来回答」

## 方式二：命令行自查

```bash
# 按关键词搜索笔记内容
obsidian-cli search-content "装饰器" --no-interactive

# 指定 vault 搜索
obsidian-cli search-content "Kubernetes" -v 知识库 --no-interactive

# 列出某个 pillar 下的所有笔记
obsidian-cli list
```

## 如何让查询更有效

1. **写好 frontmatter**：`tags`、`pillar`、`type` 是关键索引字段。
2. **保持永久笔记的原子性**：一个概念一篇笔记，搜索命中率更高。
3. **多用双向链接**：`[[相关概念]]` 越多，交叉查询时信息越丰富。
4. **定期运行 `vault统计.py`**：发现孤儿笔记后及时挂入 MOC。
5. **给笔记写摘要**：永久笔记第一段应该是该概念的简明定义，方便提取摘要。

## 查询 vs 回想

| 场景 | 方式 |
|------|------|
| 我知道要查什么关键词 | 直接搜索或问我 |
| 我想看这周学过的所有东西 | 看 `知识汇出-*.md` 或 `周回顾-*.md` |
| 我想系统梳理一个领域 | 打开对应 MOC（如 `AI学习-MOC`） |
| 我想了解笔记之间的关系 | 在 Obsidian 中打开 Graph View |
| 我想跨领域交叉思考 | 问我，我会跨 pillar 搜索并综合 |
