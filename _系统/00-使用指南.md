# 知识库使用指南

本知识库采用 **PARA + Zettelkasten** 的混合方法，强调：

- 一个概念一个永久笔记
- 笔记之间用双向链接连接
- 通过 MOC（Map of Content）导航
- 收件箱快速捕获，每周回顾

## 目录结构

```
00-收件箱          # 快速捕获
99-归档            # 不再活跃的笔记
语言学习           # 语言学习 pillar
运维学习           # 运维学习 pillar
AI学习             # AI学习 pillar
Linux学习          # Linux学习 pillar
_系统              # 模板、脚本、约定
```

## 五种笔记类型

见 `_系统/01-笔记模板/`：

| 类型 | 用途 | 存放位置 |
|------|------|----------|
| 闪念笔记 | 快速捕获 | 收件箱 |
| 文献笔记 | 读 / 看 / 听后整理 | pillar 内相关子目录 |
| 永久笔记 | 一个概念，长期复用 | pillar 内 `02-基础概念` |
| 项目笔记 | 有目标、有截止日期 | pillar 内 `04-项目与案例` |
| MOC | 目录 / 导航页 | pillar 根目录或 `_系统` |

## 命名与链接

- **文件名**：尽量用完整中文 / 英文概念名，允许空格，Obsidian 会自动处理。脚本生成时会自动加上 `YYYYMMDD-` 前缀。
- **链接**：使用 wikilink `[[目标笔记]]` 或 `[[目标笔记|显示文本]]`。
- **标签**：用 `#标签/子标签` 形式，如 `#AI/LLM`、`#运维/K8s`。
- **Frontmatter**：见 [[_系统/02-约定/frontmatter约定|frontmatter 约定]]。

## 使用脚本让知识库生长

在终端运行：

```bash
python _系统/03-脚本/新建笔记.py
python _系统/03-脚本/周回顾.py
python _系统/03-脚本/vault统计.py
python _系统/03-脚本/重建dashboard.py
# 迭代、校验并推送，触发 GitHub Actions 自动部署
python _系统/03-脚本/自动迭代并推送.py
```

> 如果没有安装 Python，可从 Microsoft Store 或 python.org 安装。Windows 用户推荐用 Git Bash 或 PowerShell 运行。

## Obsidian 推荐配置

- **Templater**：自动插入模板
- **Dataview**（可选）：基于 frontmatter 做查询
- **Periodic Notes**：日报 / 周报 / 月报
- **Tag Wrangler**：标签管理
- **Graph Analysis**：查看笔记网络

## VSCode 推荐配置

- **Markdown All in One**：快捷键、目录
- **Foam**：链接自动补全、图谱
- **Markdown Mermaid**：图表
- **Todo Tree**：待办聚合
- **Python**：运行脚本

已在 `.vscode/` 中预置推荐扩展与工作区设置，用 VSCode 打开 vault 根目录即可生效。
