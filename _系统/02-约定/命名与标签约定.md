# 命名与标签约定

## 文件名

- **永久笔记**：完整概念名，如 `20260717-大语言模型.md`
- **文献笔记**：`20260717-文献-<来源简称>-<标题>.md`
- **项目笔记**：`20260717-<项目名>.md`
- 脚本生成时会自动加上 `YYYYMMDD-` 前缀，方便按时间排序

## 标签体系

### 顶级标签

- `#AI` — AI学习相关内容
- `#Python` — Python 编程学习相关内容
- `#运维` — 运维学习相关内容
- `#Linux` — Linux 学习相关内容
- `#meta` — 知识库元信息
- `#待处理` — 需要后续整理

### 子标签示例

- `#AI/LLM`
- `#AI/Agent`
- `#AI/工具`
- `#Python/基础`
- `#Python/进阶`
- `#Python/标准库`
- `#Python/第三方库`
- `#Python/异步`
- `#Python/测试`
- `#运维/K8s`
- `#运维/Docker`
- `#运维/监控`
- `#运维/CI-CD`
- `#Linux/基础`
- `#Linux/文件系统`
- `#Linux/权限`
- `#Linux/进程`
- `#Linux/网络`
- `#Linux/练习`
- `#Linux/迭代`

## 链接

- 用 `[[笔记名]]` 在笔记之间建立连接。
- 链接到 MOC 时可用 `[[AI学习-MOC|AI学习]]` 改变显示文本。
- 跨 pillar 链接用 vault-root 相对路径：`[[语言学习/语言学习-MOC|语言学习]]`。
