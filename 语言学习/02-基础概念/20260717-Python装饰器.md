# Python 装饰器

## 定义

装饰器（Decorator）是一个接收函数作为参数、返回一个新函数的高阶函数，用于在不修改原函数代码的前提下扩展其行为。

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@my_decorator
def hello():
    print("hello")

hello()
# 输出: 调用 hello
#       hello
```

## 为什么重要

- **关注点分离**：把横切逻辑（日志、权限、缓存）从业务代码中抽离
- **可复用**：一个装饰器可以应用到任意多个函数
- **可组合**：多重装饰器可以叠加，如 `@auth @log @cache`

## 相关概念

- [[闭包]] — 装饰器本质上依赖闭包来保存外层状态
- [[高阶函数]] — 装饰器是高阶函数的典型应用
- [[functools.wraps]] — 保留被装饰函数的 `__name__` 和 `__doc__`

## 应用

| 场景 | 示例 |
|------|------|
| 计时 | `@timeit` 包裹函数，记录执行时间 |
| 日志 | `@log` 自动记录函数调用和返回值 |
| 权限校验 | `@requires_auth` 检查用户是否登录 |
| 缓存 | `@lru_cache` 缓存函数结果（functools 内置） |
| 重试 | `@retry(max=3)` 失败自动重试 |
