# Python 数据类型与结构

## 是什么

Python 中的数据主要分为两类：**不可变的基本类型**和**可变的容器类型**。前者包括 `int`、`float`、`str`、`tuple`、`bool`；后者包括 `list`、`dict`、`set`。

## 为什么重要

数据类型是编程的「建材」。选错类型，代码又慢又难读。比如用 `list` 做成员检查是 O(n)，用 `set` 是 O(1)——选择决定性能。

## 核心要点

- `list` 有序可变，适合顺序存取；`tuple` 有序不可变，适合做键和函数返回值。
- `dict` 是 Python 的发动机——从对象属性到函数参数，底层都是字典。
- `set` 自动去重，交/并/差运算一行搞定，成员检查极快。
- 字符串不可变，每次拼接都会创建新对象——大批量拼接用 `"".join()`。
- 变量名只是标签，指向对象；赋值不复制数据，只是换了标签贴的位置。

## 一句话带走

> list 存顺序，dict 存映射，set 存唯一；三者组合能表达 90% 的数据结构需求。
