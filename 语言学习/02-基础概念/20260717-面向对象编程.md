# 面向对象编程（OOP）

## 是什么

Python 的 OOP 核心就是 **类（class）** 和 **实例（instance）**。类是一张「蓝图」，实例是按蓝图造出来的对象。三大支柱：封装（藏细节）、继承（复用代码）、多态（统一接口）。

## 为什么重要

不学 OOP，看别人的框架代码就像看天书。Django、FastAPI、SQLAlchemy 全是用类搭起来的。你写的脚本超过 500 行时，不用类会越来越难维护。

## 核心要点

- `class MyClass:` 定义类；`__init__` 是构造函数，`self` 指向实例本身。
- `@property` 把方法伪装成属性；`@staticmethod` / `@classmethod` 区分普通方法和类方法。
- 继承用 `class Child(Parent):`；`super()` 调用父类方法，避免硬编码父类名。
- `__str__` 定义 `print()` 的输出；`__repr__` 定义调试时的显示。
- 「鸭子类型」：不管对象是什么类，只要它有你需要的方法，就能用。Python 不强制接口。

## 一句话带走

> Python 的 OOP 不是束缚手脚的条条框框，而是帮代码从「能跑」进化到「好改」的组织方式。
