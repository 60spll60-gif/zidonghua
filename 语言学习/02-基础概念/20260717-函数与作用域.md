# 函数与作用域

## 是什么

函数是一段可复用的代码块。Python 中函数是一等公民——可以赋值给变量、作为参数传递、作为返回值。「作用域」决定变量在哪里可见：遵循 **LEGB** 规则（Local → Enclosing → Global → Built-in）。

## 为什么重要

理解作用域能避免 90% 的「变量未定义」和「变量被意外修改」的 bug。理解函数是一等公民，才能写出装饰器、闭包、回调这些 Python 高级特性。

## 核心要点

- `def` 定义函数，`lambda` 定义匿名单行函数。
- 参数有四种：位置参数、默认参数、可变参数（`*args`）、关键字参数（`**kwargs`）。
- 函数内部用 `global` 声明才能修改全局变量；用 `nonlocal` 修改外层闭包变量。
- 函数式编程三件套：`map`（映射）、`filter`（过滤）、`reduce`（归约）。
- 类型标注不是强制的，但加上后 IDE 能自动补全、mypy 能静态检查。

## 一句话带走

> 函数不是只能「调用」——它可以「传递」和「组合」。这是 Python 优雅的根源。
