# 异步编程 · asyncio

## 是什么

异步编程是一种「在等待时不阻塞」的编程方式。Python 的 `asyncio` 通过 **事件循环（event loop）** 管理多个协程，用 `async/await` 语法让代码看起来像同步但实际是异步执行。

## 为什么重要

你写爬虫，等网页响应的时候 CPU 在发呆——异步就是让 CPU 在等待时去干别的事。一个异步爬虫可以同时发 100 个请求，同步的只能一个接一个排队。

## 核心要点

- `async def` 定义协程函数；`await` 暂停当前协程，交出控制权给事件循环。
- `asyncio.gather()` 并发跑多个协程；`asyncio.create_task()` 把协程包装成 Task 扔进后台。
- IO 密集型（网络请求、文件读写）是异步的主场；CPU 密集型（计算）不适合，要用多进程。
- `aiohttp` 替代 `requests`；`asyncpg` 替代 `psycopg2`——异步要全家桶替换。
- Python 3.11+ 的 `asyncio.TaskGroup` 提供更好的异常处理，推荐替代 `gather`。

## 一句话带走

> 同步是「排队等」，异步是「拿号等」——号拿了就去做别的事，轮到你时再回来。
